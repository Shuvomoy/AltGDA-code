# Lean verification of the AltGDA convergence theorem

This self-contained Lake project formalizes the dimension-free global
`O(1/T)` ergodic convergence theorem for alternating gradient descent-ascent
in finite matrix games. It covers the mathematical results corresponding to
Sections 2--3 and Appendix A of the manuscript. The numerical Lyapunov-LMI and
performance-estimation studies are outside its scope.

The proof is exposed through three public declarations:

1. `AltGDA.ergodicGap_le_of_gtWitness` proves the ergodic-gap rate for the
   projected AltGDA trajectory from a supplied strictly complementary
   Goldman--Tucker saddle witness.
2. `AltGDA.exists_gtWitness` proves that every finite nonempty matrix game has
   such a witness.
3. `AltGDA.manuscript_main_theorem` combines witness existence with the rate
   theorem for a real payoff matrix while retaining the selected witness and
   its separation parameter explicitly.

## Prerequisites

- Git, for retrieving the pinned Mathlib dependency.
- [elan](https://github.com/leanprover/elan), the Lean toolchain manager.
- Network access for the first build.

The project pins Lean 4.32.0 in `lean-toolchain` and Mathlib 4.32.0 in
`lakefile.toml`; `lake-manifest.json` records the exact dependency revisions.

## Build and verify

From this directory, build the project and run the explicit dependency audit:

```bash
lake build
lake env lean AxiomAudit.lean
```

The second command prints the axioms used by each public declaration. Each
declaration is expected to depend only on `propext`, `Classical.choice`, and
`Quot.sound`, the standard foundational axioms used by Mathlib.

Lake creates dependency and build products under `.lake/`. That directory is
ignored by `.gitignore`, is not part of this portable source package, and can
be deleted and regenerated by running `lake build` again.
