# AltGDA-code

> 

The paper proves a dimension-free global `O(1/T)` ergodic convergence rate for
alternating gradient descent–ascent (AltGDA) in finite matrix games. 

## Repository contents

- [`Julia-code/`](Julia-code/) contains the Julia scripts, environments, tests,
  and data for the Lyapunov–LMI diagnostics and finite-horizon performance
  estimation experiments.
- [`Lean-code/`](Lean-code/) contains the independently buildable Lean 4
  formalization and axiom audit for the main convergence theorem.

Each directory has its own README with reproduction instructions.
